# Validador de Transações

Programa em Java que verifica se uma transação é suspeita e se está de acordo com o limite do cartão.

## O que ele faz
- Checa o valor da transação
- Checa o horário
- Checa se o valor está dentro do limite.
- Checa se a transação é suspeita.

## Como rodar
1. Baixe o projeto
2. Abra na sua IDE
3. Execute a classe Main

## Linguagens:
- Java
